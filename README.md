本仓库用于存放可持续维护的工程源码。当前已明确纳入的项目：

- [Green Migration（绿色迁移工具）](projects/green-migration/README.md) — v1 现场验证过的 Shell/Jenkins 基线与 Go v2 后续重建迭代。

> **公开仓库注意**：不提交生产密码、私钥、内部客户数据、环境快照或未经许可分发的第三方二进制。现场运行前必须使用受控凭据、检查目标与回滚边界。

不同项目分目录维护；具体版本、来源、测试范围以各项目自己的 README/CHANGELOG 为准。本仓库中的源码上传不自动代表已通过生产验收。
